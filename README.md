Caesar Cipher Implementation

Objective

To implement a Caesar Cipher encryption and decryption tool using Python.

Description

The Caesar Cipher is a simple encryption technique where each letter in the message is shifted by a fixed number of positions in the alphabet.

Features

- Encrypt messages
- Decrypt messages
- Handles uppercase and lowercase letters
- Ignores non-alphabet characters

Tools Used

- Python

Outcome

This project helped in understanding basic cryptography concepts and how encryption works.
